How to use it

Set up in three steps

Open Now Playing

The main window shows a live preview of the player.

Allow it to control Spotify

macOS asks once: "Now Playing wants to control Spotify". Click OK.

Add the widget

Click the date and time in the menu bar › Edit Widgets › search Now Playing.
