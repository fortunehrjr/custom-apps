Under the hood

Built with

All five apps are native Mac apps written in Swift. No web views, no Electron, no tracking. That's why they're tiny and fast.

Clipper

Uses the Mac's Accessibility feature (the same one screen readers use) to move and size windows, and listens for your keyboard shortcuts.

Built with swiftc directly from a shell script, no Xcode project. Windows are moved through AXUIElement; drag-to-snap watches mouse events; global hot keys use Carbon RegisterEventHotKey. Signed with an identifier-based designated requirement so the Accessibility grant survives rebuilds.

AXUIElementCarbon hot keysNSEvent monitorsSwiftUI onboarding

Ferry

Reads how fast each drive is reading and writing, and listens to the progress Finder already shares, to know file names, sizes and percentages.

IOKit IOBlockStorageDriver statistics give per-drive byte counters. FSEvents spots new files so Ferry can subscribe with Progress.addSubscriber(forFileURL:) to Finder's published copy progress, which also allows cancel(). The floating window is a non-activating NSPanel wrapped in NSGlassEffectView. Finder's copy window is moved with the Accessibility API.

IOKitFSEventsNSProgressSwift ChartsWidgetKitNSGlassEffectViewXcodeGen

Now Playing

Asks Spotify what's playing, the same way the Shortcuts app can, and shows it in your menu bar and as a widget.

AppleScript over Apple Events (NSAppleScript) polls Spotify off the main thread and sends play/pause/skip. A MenuBarExtra hosts the mini player; a WidgetKit extension renders the same SwiftUI layouts, sharing state through a sandbox file exception.

Apple EventsMenuBarExtraWidgetKitSwiftUI layoutsXcodeGen

Orbit

A timer with a hand-drawn dial, plus a music card that can talk to Spotify, Music and YouTube, or play files straight from your Mac.

A Swift Package (swift build) with an @Observable timer model. Music comes from AppleScript bridges to Spotify, Music, Chrome and Safari (YouTube via page JavaScript) and AVFoundation for local files. Liquid Glass via glassEffect; end-of-session alerts via UserNotifications.

Swift Package ManagerObservationAVFoundationUserNotificationsLiquid Glass

Stash

Notices each time you copy something, saves it on your Mac, and shows your history in a glass panel when you press a shortcut.

A Swift Package. A tolerant timer compares NSPasteboard.changeCount twice a second and only reads the clipboard when it changes, skipping org.nspasteboard.ConcealedType data. The panel is a non-activating NSPanel in NSGlassEffectView, opened by a Carbon hot key; "Paste for me" posts ⌘V with CGEvent. History is JSON plus PNG files in Application Support.
