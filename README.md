# Custom Apps website

The website for four small Mac apps: **Clipper**, **Ferry**, **Now Playing** and **Orbit**.

**Live site:** https://fortunehrjr.github.io/custom-apps/

Each app has its own repo, and downloads live on each repo's Releases page:

- [Clipper](https://github.com/fortunehrjr/Clipper): snap, resize and lock windows
- [Ferry](https://github.com/fortunehrjr/Ferry): live speed and progress for file copies
- [Now Playing](https://github.com/fortunehrjr/Now-Playing): Spotify mini player for the menu bar and widgets
- [Orbit](https://github.com/fortunehrjr/Orbit): focus timer with your music built in

Plain HTML, CSS and JavaScript with [GSAP](https://gsap.com) animations. No build step: open `index.html` or serve the folder.
