New versions

Updating is painless

Got a newer version from a friend, or built one yourself? Here's how to swap it in without losing your settings.

Quit the app

Use Quit in its menu bar icon or app menu, so the old copy isn't running.

Open the new .dmg

Double-click the new installer you received.

Drag to Applications, choose Replace

macOS asks whether to replace the existing app. Click Replace.

Open it again

Your settings stay exactly as they were. If an app asks for a permission again, just allow it.

What's kept when you update

  • All your settings and choices
  • Ferry's transfer history
  • Orbit's timer lengths and today's sessions
  • Clipper's Accessibility permission (it stays valid across updates)

Ferry may ask again for Accessibility permission if you use its "Ferry" mode.

Each app has its own GitHub repo. You need Xcode 26+. Ferry and Now Playing use XcodeGen (brew install xcodegen).

Clipper

# Compiles with swiftc and installs to /Applications
git clone https://github.com/fortunehrjr/Clipper && cd Clipper
./build.sh --install

Ferry

git clone https://github.com/fortunehrjr/Ferry && cd Ferry
xcodegen generate
xcodebuild -project Ferry.xcodeproj -scheme Ferry \
  -configuration Release -destination 'generic/platform=macOS' \
  -derivedDataPath build/DD build

Now Playing

git clone https://github.com/fortunehrjr/Now-Playing && cd Now-Playing
xcodegen generate
xcodebuild -project NowPlaying.xcodeproj -scheme NowPlaying \
  -configuration Release -destination 'generic/platform=macOS' \
  -derivedDataPath build/DD build

Orbit

# Swift Package; output goes to dist/Orbit.app
git clone https://github.com/fortunehrjr/Orbit && cd Orbit
./build.sh

📦 Make a new installer

mkdir stage && cp -R Ferry.app stage/
ln -s /Applications stage/Applications
hdiutil create -volname Ferry -srcfolder stage \
  -format UDZO Ferry.dmg

🧩 Widgets need signing

Ferry and Now Playing include Notification Center widgets. macOS only loads widgets from apps signed with an Apple developer identity. A free Apple ID works: add it in Xcode › Settings › Accounts, then pick your Personal Team under Signing & Capabilities for both targets.
